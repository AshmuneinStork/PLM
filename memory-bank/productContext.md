# Product Context — i18n RU

## Проблема
- Весь UI только на английском, русскоязычным пользователям сложно работать.

## Пользователи
- Primary: русскоязычные инженеры/админы PLM.
- Secondary: англоязычные, оставляем EN дефолтом с fallback.

## Сценарии
1. Пользователь открывает app с ru-браузером → видит RU.
2. Переключает EN/RU в хедере (и на /login) → выбор сохраняется.
3. Даты/числа форматируются по локали.

## UX
- Переключатель рядом с ThemeToggle в Header + компакт на login/setup.
